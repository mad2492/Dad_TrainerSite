# Roadmap

Purpose: keep the project phased so it does not become too big too soon.

## Phase 1: Public Website

Goal: create a professional online footprint.

Possible scope:

- One-page mobile-friendly website
- About section
- Services section
- Testimonials/results section
- Contact form or consultation request
- Social links
- Basic local SEO

Definition of done:

- Easy to read on iPhone
- Dad is comfortable sharing the link
- New client can understand what he offers
- New client can contact him easily

## Phase 2: Clickable Portal Demo

Goal: test whether the portal idea feels useful before building it.

Possible scope:

- Fake client profile
- Example diet plan
- Example session recap
- Example admin screen
- No real login or client data yet

Definition of done:

- Dad can tap through it on his phone
- He can say what feels useful or unnecessary
- We can identify the smallest useful portal feature

## Phase 3: Client Portal MVP

Goal: support real clients with a small private area.

Possible scope:

- Secure login
- Client profiles
- Diet plan viewer
- Session notes
- Simple trainer admin

Definition of done:

- One or two real clients can use it
- Dad can update basic info from his iPhone
- Nothing sensitive is exposed publicly

## Phase 4: Progress Tracking

Goal: add engagement and accountability if clients want it.

Possible scope:

- Weight
- Measurements
- Photos
- Check-ins
- Progress timeline

## Phase 5: Optional Payments

Goal: add payment support only if it saves time.

Possible scope:

- Payment status tracking
- Payment links
- Stripe, Square, or external links

Decision rule:

- Do not add card processing unless the fee is worth the convenience.
