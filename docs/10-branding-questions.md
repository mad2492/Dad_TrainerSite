# Branding Questions

Purpose: decide the public identity before making a polished website mockup.

We now know enough about the online training offer to start asking brand questions.

## Brand Structure

Decision: Pete and Lisa Fonseca together.

They should be presented as a shared coaching brand because they are always together and both bring real experience.

Decisions:

- The brand name is Fonseca Fitness.
- The Fonseca name should be part of the brand.
- Clients do not need to choose Pete or Lisa up front; the program will recommend the right fit.
- The website should be accessible to everyone, not positioned only as local.

Open questions:

- If both are included, do they offer the same services or different specialties?
- Should the online program feel like one joint program or a program with two coach paths behind the scenes?

## Name

Decisions:

- Working brand name: Fonseca Fitness.
- Fonseca should be part of the brand.
- "Fitness" is the chosen broad category word for now.

Open questions:

- Should the online program have its own sub-name under Fonseca Fitness?
- Should the packages have branded names or plain goal-based names?

## Positioning Statement

Possible message to refine:

> Personalized online training, nutrition, and weekly check-ins from experienced coaches, designed to feel as close as possible to one-on-one training.

Questions:

- Does that sound accurate?
- Is "coach" the right word, or does Pete prefer "trainer"?
- Should the message emphasize experience, results, accountability, bodybuilding background, lifestyle change, or personal attention?

## Visual Direction

The requested feel is a mix of:

- Old-school bodybuilding and experience
- Clean, professional, and trustworthy
- Direct, tough, no-nonsense coaching
- Warm, personal, supportive coaching
- Performance and transformation focused
- Accessible to everyone, not only local

Current brand specs from logo exploration:

- Primary Navy: `#0F2740`
- Primary Red: `#B3262D`
- Off-White: `#F5F3EE`
- Primary wordmark: bold athletic slab-serif or varsity-inspired block font
- Supporting text/tagline: clean sans-serif such as Montserrat, Gotham, Inter, or Avenir Next

Questions:

- What should the site feel like when someone opens it?
- Are there colors Pete likes or hates?
- Should it feel more classic/old-school or modern?
- Should photos be gritty gym photos, clean professional portraits, client results, or a mix?
- Logo is still to be created.
- Are there existing shirts, signs, business cards, or social pages to match?

## Logo Usage Direction

Recommended use:

- Primary full logo with tagline: homepage, business cards, social banners, marketing materials
- Primary full logo without tagline: general branding, shirts, posters, profile headers
- Horizontal website header version: website navbar/header, email signatures, web/app top navigation
- Simplified circle icon: social profile images, app icon, favicon, watermark
- Circle badge with "Strength - Nutrition - Accountability": merch, stickers, gym banners, premium brand placements
- White/reversed version: dark backgrounds, navy shirts, embroidery, video overlays
- One-color navy version: embroidery, print invoices, minimal merchandise, single-color applications

Still needed:

- Separate transparent PNG files for each logo version
- SVG/vector recreation or cleanup
- Favicon/icon export
- Confirm whether tagline should always be "Stronger Together. Better Together."
- Confirm whether the circular badge should use "Strength - Nutrition - Accountability"

## Package Direction

Packages should be based on client need.

Examples:

- Weight Loss
- Weight Gain
- Bodybuilding
- Over 50 Fitness
- Female Fitness

Open questions:

- Which packages should exist at launch?
- Are "weight gain" and "muscle gain" the same package?
- Should package names be plain and direct, or branded?
- Does each package include the same check-in and messaging rules?
