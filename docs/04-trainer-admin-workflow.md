# Trainer Admin Workflow

Purpose: design around what Dad can comfortably do from an iPhone.

## Admin Principles

- Phone-first.
- Large tap targets.
- Minimal typing.
- No clutter.
- No complicated settings.
- Show only what he needs for the current client.

## Core Admin Screens

### Client List

- Client name
- Status or next follow-up
- Last update date
- Quick search

### Client Profile

- Current diet plan
- Session recaps
- Private notes
- Progress summary
- Contact information

### Edit Diet Plan

- Simple text sections
- Save draft
- Publish/update for client
- Optional template reuse later

### Add Session Recap

- Date
- Short note
- What they worked on
- What to do next

### Check-In Notes

- Weight
- Measurements
- Energy/compliance notes
- Follow-up needed

## Admin Questions

- What does he need to see first when opening a client?
- What should be one tap?
- What is too annoying to type?
- Would dictation from the iPhone be useful?
- Should anything be private to him only?

## Workflow Sketches

### After a Training Session

1. Open client.
2. Tap add recap.
3. Write or dictate a short note.
4. Save.

### After a Diet Check-In

1. Open client.
2. Review current plan.
3. Edit changed items.
4. Add private note if needed.
5. Save/update plan.
