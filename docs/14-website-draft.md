# Website Draft

Purpose: track the first public-facing Fonseca Fitness website draft.

## Direction

The home page now opens as a mobile-first website draft instead of a proposal memo.

The page has two main tabs:

- `Website`: public-facing draft for Fonseca Fitness.
- `Pitch`: review notes explaining the business reasoning, phased rollout, and open questions.

## Website Draft Goals

- Make Fonseca Fitness feel real enough for Pete and Lisa to react to.
- Keep the first screen simple and strong on an iPhone.
- Present Pete and Lisa as one coaching team.
- Emphasize personalized coaching instead of cookie-cutter plans.
- Show the likely online coaching rhythm before building a portal.
- Use the cleaned raster logo draft while still avoiding final-logo dependency.
