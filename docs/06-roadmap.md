# Roadmap

Purpose: keep the project phased so it does not become too big too soon.

## Phase 1: Public Website

Goal: create a professional online footprint that can convert word-of-mouth interest and introduce online training.

Possible scope:

- One-page mobile-friendly website
- About section
- Services section
- Online training section
- Testimonials/results section
- Contact form or consultation request
- Social links
- Basic local SEO
- Clear positioning: not cookie-cutter, individualized plans, decades of experience

Definition of done:

- Easy to read on iPhone
- Dad is comfortable sharing the link
- New client can understand what he offers
- New client can contact him easily
- Online prospects understand how to ask about remote coaching

## Phase 2: Clickable Portal Demo

Goal: test whether the portal idea feels useful for both current clients and future online clients before building it.

Brand structure decision: Pete and Lisa Fonseca together.

Before designing the polished mockup, decide:

- Business/program name
- Whether clients choose Pete or Lisa, or whether the program recommends the right coach
- Visual direction and tone
- Package names

Possible scope:

- Fake client profile
- Example diet plan
- Example reminder
- Example session recap
- Example admin screen
- Example online client dashboard
- Example client communication request
- No real login or client data yet

Definition of done:

- Dad can tap through it on his phone
- He can say what feels useful or unnecessary
- We can identify the smallest useful portal feature
- We can tell whether 20 to 30 online clients would be manageable with this workflow

## Phase 3: Client Portal MVP

Goal: support real clients with a small private area, starting with diets and reminders.

Possible scope:

- Secure login
- Client profiles
- Diet plan viewer
- Reminders
- Simple client communication/request flow
- Session notes
- Simple trainer admin

Definition of done:

- One or two real clients can use it
- Dad can update basic info from his iPhone
- Nothing sensitive is exposed publicly

## Phase 4: Progress Tracking

Goal: add engagement and accountability if clients want it.

Possible scope:

- Weight
- Measurements
- Photos
- Check-ins
- Progress timeline
- Online coaching status

## Phase 5: Optional Payments

Goal: add payment support only if it saves time.

Possible scope:

- Payment status tracking
- Payment links
- Stripe, Square, or external links

Decision rule:

- Do not add card processing unless the fee is worth the convenience.
